# Adoray Devocional (MVP)

App web de devocional gamificado em português com foco em inovação espiritual.

## Recursos principais

- Premium (500 moedas): usuário não perde vida ao errar lição.
- Devocional Diário Inteligente por tema + narração em áudio.
- Planos de 7, 21 e 40 dias.
- Streak com foguinho + cancelamentos + congelamento comprável (100 moedas).
- Área de oração: pedidos, marcar como respondida e gerar testemunhos.
- Diário espiritual (caderno) com personalização de folha/enfeites.
- Bíblia digital local com livro/capítulo/verso, busca, favoritos e compartilhamento em imagem.
- IA devocional personalizada por estado emocional.
- Rank por divisões e liga semanal.

## Como executar

```bash
python3 -m http.server 4173
```

Acesse: `http://localhost:4173`.
