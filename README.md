# Adoray Devocional (MVP)

App web de devocional gamificado, em português, com visual inspirado em trilhas de estudo.

## Recursos

- Tela inicial com trilha de devocionais (estilo jornada) e ilustrações em cada etapa.
- Onboarding com 6 perguntas antes de iniciar o app.
  - Perguntas **2 e 6** aceitam múltiplas opções.
  - Demais perguntas aceitam apenas 1 opção.
- Navegação inferior: Início, Bíblia, IA, Rank e Perfil.
- XP, streak, ranks e pet editável.
- Tema claro/escuro, animação no título e persistência local (`localStorage`).

## Como executar

```bash
python3 -m http.server 4173
```

Acesse: `http://localhost:4173`.
