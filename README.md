# Devocional Quest

Aplicativo web simples para acompanhar rotina devocional com:

- Streak diário com "foguinho";
- Sistema de XP e ranks (Bronze até Lendário);
- Conselheiro bíblico estilo IA (respostas baseadas em temas);
- Perfil editável;
- Pet bíblico editável.

## Como executar

Basta abrir `index.html` no navegador.

Ou rode um servidor local:

```bash
python3 -m http.server 4173
```

Depois acesse `http://localhost:4173`.
